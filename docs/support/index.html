Chrome, Edge, and Firefox are available from their extension stores. Safari for macOS is available on the Mac App Store. See Safari setup and the browser comparison.

Safari for macOS

The Safari version is available free on the Mac App Store. Requires macOS 14 or later.

  1. Install Tab Manager v2 from the Mac App Store, then open the installed app.
  2. Open Safari Settings → Extensions and enable Tab Manager v2 for the profile you want to use.
  3. Allow website access when Safari asks so Tab Manager can show tab titles and URLs. If a title or URL is missing, check Safari’s website access settings and refresh the manager.
  4. Click the Safari toolbar icon for the popup. Control+O opens a full browser tab, Control+T opens a separate manager window, and Option+B cycles recently used tabs.

Safari shows normal windows in the current profile and the active tab groups Safari exposes. Inactive groups and private windows are excluded.

With “Show tab icons” on, Safari loads icons from websites you have allowed. Settings offers “Allow website access” when permission is missing. Unavailable icons use the same neutral placeholder as other browsers.

Quick start

  1. Open the extension from the browser toolbar, or open it in its own tab or window for a larger view.
  2. Press / to search open tabs across all windows. Press Command + K on macOS or Alt + K on Windows/Linux for the command palette. > remains an alias; ? opens shortcut help.
  3. Select matching tabs to close, reload, pin, copy, or export them together. Moving and grouping are available where supported by your browser.

In Chrome, Edge, and Firefox, use Window actions to move selected tabs to a window’s beginning or end, or drag them onto its header drop targets. Safari does not support tab moving or reordering.

Your browser’s tab groups

In Chrome, Edge, and Firefox, supported tab groups can be named, recolored, collapsed, or ungrouped. Select tabs in the same window to create a group. Safari does not expose group editing; only the active groups are visible.

Include or hide browser history

Chrome, Edge, and Firefox include browser history in search by default. Turn off Include browser history in results in Settings to show only open tabs. Safari searches open tabs only. Read the privacy policy for more about browser access and saved data.

Firefox containers

In Firefox, containers keep separate sign-ins apart. Tab Manager v2 can work with tabs in those containers where available. Containers are separate from tab groups and require the installed extension.

Settings and appearance

Open Settings and search for theme, contrast, layout, toolbar visibility, tab details, or search preferences. Previews show what will change. Safari saves settings locally; other browsers may sync settings if browser sync is enabled. This website has its own theme and language settings.

Tab actions and copying

Right-click a tab, window header, or group for its actions. Hover a tab for selectable title and URL details, with copying and expansion for long text. In full view, select tabs and type in the corner action search to move, reload, copy, or save them together. Press Ctrl+Shift+F to focus it; with no selection, this shortcut focuses the toolbar. Use Escape to go back or collapse the actions. Copy titles, URLs, both, CSV, TSV, JSON, or Markdown, or download CSV, TSV, JSON, or Markdown. Copying and exporting keep your selection.

Quick actions in lite mode

Lite popup mode keeps finding, switching, closing, pinning, reloading, copying, and tab details close at hand. Open full Tab Manager for bulk actions, exports, Settings, and shortcut help. Moving and grouping require browser support. Escape resets ordinary search; in a menu or dialog, it dismisses that overlay first.

Using the demo

The interactive demo uses the real extension interface with sample tabs, groups, and history. Changes stay in the demo and do not affect your actual browser tabs.

  • Refreshing or switching workspaces restores sample tabs and keeps demo settings, including its independent theme, for this browser tab’s session. "Start over" also resets demo settings. Saved website theme and language stay unchanged.
  • Tab activation, reloads, window focus, and browser history are simulated. Firefox containers and browser toolbar integration require the installed extension.
  • Copy actions copy sample URLs to your clipboard and depend on browser clipboard access.
  • The optional 1,500-tab workspace lets you try the layout with sample data. It does not measure your browser’s memory use.
  • The embedded extension interface is shown in English. Website text supports English, Simplified Chinese, and Traditional Chinese.

Get help

Search existing GitHub issues for the behavior you are seeing. If you cannot find a match, open a bug report or feature request.

Make a report easy to reproduce

  • Include your browser name and version, operating system, and Tab Manager v2 version.
  • Describe the steps, what you expected, and what actually happened. Add a screenshot when it helps explain the problem.
  • Say whether the problem occurs in the installed extension or the website demo. For demo problems, include the workspace preset and the page URL.
