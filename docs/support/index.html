Install

Choose the store for your browser. After installation, open Tab Manager v2 from the browser toolbar.

Chrome Web Store Firefox Add-ons Microsoft Edge Add-ons

Chrome, Edge, and Firefox are supported. Feature availability follows the APIs exposed by your browser. Safari is not supported by this project; the limitation is tracked in issue #2545.

Quick start

  1. Open the extension from the browser toolbar, or open it in its own tab or window for a larger view.
  2. Press / to search open tabs across all windows. Press > for the command palette or ? for shortcut help.
  3. Select matching tabs, then move, group, or close them in bulk.

Use Window actions to move selected tabs to a window’s beginning or end, or drag them onto its header drop targets. A destination tab’s menu can move the selection before or after that tab.

Browser features

Native tab groups

Where your browser supports native tab groups, you can rename, recolor, collapse, or ungroup them from Tab Manager v2. To create a group, select tabs in the same window. Custom window names are not a feature; use tab groups for named collections of tabs.

Optional browser history search

In settings, enable "Include browser history in results" to include browser history in search. Turn it off to search without history results. This feature uses the browser's history permission. Read the privacy policy for details about browser access and stored data.

Firefox containers

Container-aware workflows are available in Firefox when the browser exposes the required APIs. They use container identities and related cookie-store information. Firefox containers are separate from native tab groups and require the installed extension.

Settings and appearance

Use extension settings to change theme, tab width, font size, toolbar visibility, URL display, and search preferences. Settings use browser sync storage when available, with local storage as a fallback. Website theme and language controls apply to this website; the installed extension has its own settings.

Using the demo

The interactive demo uses the real extension interface with sample tabs, groups, and history. Changes stay in the demo and do not affect your actual browser tabs.

  • Refreshing or switching workspaces restores sample tabs and keeps demo settings, including its independent theme, for this browser tab’s session. "Start over" also resets demo settings. Saved website theme and language stay unchanged.
  • Tab activation, reloads, window focus, and browser history are simulated. Firefox containers and browser toolbar integration require the installed extension.
  • Copy actions copy sample URLs to your clipboard and depend on browser clipboard access.
  • The optional 1,500-tab workspace explores the interface with simulated data; it is not a native browser memory benchmark.
  • The embedded extension interface is shown in English. Website text supports English, Simplified Chinese, and Traditional Chinese.

Get help

Search existing GitHub issues for the behavior you are seeing. If you cannot find a match, open a bug report or feature request.

Browse existing issues Open an issue

Make a report easy to reproduce

  • Include your browser name and version, operating system, and Tab Manager v2 version.
  • Describe the steps, what you expected, and what actually happened. Add a screenshot when it helps explain the problem.
  • Say whether the problem occurs in the installed extension or the website demo. For demo problems, include the workspace preset and the page URL.
