# v3.0: six key manual checks

Use PR #2671 / `codex/prepare-v3-release`. This is a short acceptance pass, about 10 minutes; you do not need to work through the earlier 96-item matrix. The manifest remains 2.7.2 until the 3.0.0 release PR is merged.

1. **Escape reset.** Search for a tab, right-click a result, and press Escape. Only the menu closes; the query remains. Press Escape again: both query and dropdown disappear. Search again to confirm it starts normally.
2. **Downloads and selection.** Select two or three tabs. Open the palette with Command+K and choose Export. Check CSV, TSV, JSON, and Markdown are offered; download `.tsv` and `.md`, open them, and check titles/URLs. Your selection and format picker should remain available. Also try Copy title and URL.
3. **Palette and menus.** Open/cancel Command+K from a populated search: retain its query and scroll position. Right-click a tab, window header, and group header; each menu should clearly refer to that target and the current selection.
4. **Drag destinations.** Move sample tabs to a window/group Beginning and End, including a collapsed group and beneath the count badge. Headers/cards should stay still. Dragging a whole group beside another should preserve it as a separate named/color group.
5. **Long tab details.** Hover a tab, move onto the dark tooltip, select/copy text, and expand a long title or URL. Copy should include the complete value. Move away and confirm normal dismissal.
6. **Settings feel.** Scroll the single page and search for a setting. Change a theme or line limit and check the right-side preview reacts; controls should be aligned and easy to focus. Close/reopen Settings and check the preference persists. The browser/popup preview should have one toolbar.

Optional if you use lite mode: reopen the browser popup and check quick tab actions still work, while Settings/organization route into full Tab Manager.

The user reported all six checks working on October 14. Local regression coverage covers search reset from input/result focus, first-versus-second Escape in full/lite views, all four file types, complete UTF-8 contents, selection retention, and picker retention. The subsequent website-video refresh recorded 165 local Linux browser cases across 17 passing test files, including existing visual checks. Snapshot baselines remain unchanged, and hosted CI is still deferred at the user's request.
