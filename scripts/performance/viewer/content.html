Methodology and data
  • Download size is the exact Chrome or Firefox ZIP, except packages marked as source rebuilds. Startup JavaScript counts the popup's initial scripts.
  • Interface benchmarks use a production React profiling build with simulated tab metadata in Chromium. Versions are compared only within the same measurement set. These timings do not measure website loading, cold browser launch, or native browser APIs.
  • Startup and search use the selected source-tab workload plus 12 destination tabs. Search measures a specific matching query and includes the application's debounce. Drag rendering and post-drag JavaScript heap use their own workload, shown below.
  • Timings show the median and observed minimum–maximum, not confidence intervals. Historical versions were measured after release from their frozen source. Capture dates and original records are preserved in the downloads.
